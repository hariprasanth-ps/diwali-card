# Diwali Card 🪔

An elegant, personalized Diwali greeting. Pure HTML, CSS and JavaScript — no build step.

## Structure
```
diwali-card/
├── index.html          Page markup
├── css/styles.css      All styling (design tokens at the top)
└── js/
    ├── effects.js      Embers + fireworks (canvas)
    ├── personalize.js  Names from the URL, share-link builder
    └── main.js         Wires everything together
```

## Run locally
Open `index.html` in a browser.

## Deploy (GitHub Pages)
Push this folder to a repo → Settings → Pages → Deploy from `main` / root.

## Personalize
Add names to the link:
- `…/#Priya`
- `…/#Priya-from-Arjun`
